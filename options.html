Form Receipt

Googleフォームの送信完了を確認してから、回答の控えをここに残します。Webhookで外部に送ることもできます。

送信履歴

Webhookでの送信

Webhook URLの作り方

Discord

  1. 控えを受け取りたいチャンネルの ⚙️「チャンネルの編集」を開きます（自分だけのサーバーがおすすめです）。
  2. 「連携サービス」→「ウェブフック」→「新しいウェブフック」を押します。
  3. 「ウェブフックURLをコピー」を押し、上の欄に貼り付けます。

Slack

  1. Slack API の「Your Apps」でアプリを作成し、「Incoming Webhooks」をオンにします。
  2. 「Add New Webhook to Workspace」で送信先のチャンネルを選び、表示されたURLを貼り付けます。

Google Chat

  1. スペースの名前 →「アプリと統合」→「Webhook を追加」で作成し、URLを貼り付けます（Google Workspace のアカウントが必要です）。

そのほか

上記以外のURLには、回答をJSON形式でPOSTします（Zapier・Make・n8n・自作のサーバーなどで受け取れます）。JSONの text には読みやすい形の全文が入るので、Mattermost など text を表示するサービスではそのまま読めます。

保存するときに、送信先のサイトへのアクセス許可を求める画面が出ます。許可したサイト以外には送信しません。

Webhook URLを知っている人は誰でもそこに送信できるので、他人には教えないでください。
